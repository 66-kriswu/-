# STM32F407 四轴机械臂固件

基于 FreeRTOS 与 CMSIS-RTOS V2 的四轴步进机械臂固件，运行于 STM32F407VET6。上位机通过串口发送 G1 直线指令，固件完成插补与逆解后输出四路步进脉冲，并全程监测限位与急停。

![一次 G1 指令的全链路数据流](docs/dataflow.png)

## 工程框架

按板级启动、硬件抽象、运动学、协议命令、任务调度、故障记录六层组织。main.c 初始化时钟与外设后启动调度器，5 个任务负责命令解析、运动控制、安全监测、指示灯与诊断输出；串口数据经命令队列交给运动任务，逐毫秒插补后由脉冲层下发。可调参数集中在 arm_config.h，业务逻辑集中在 arm_ 前缀模块。

![固件模块思维导图](docs/mindmap_modules.png)

## CubeMX 配置

8 MHz 晶振经 PLL 倍频至 168 MHz。USART2 9600 8N1 接上位机，DMA1 Stream5 循环接收并以 IDLE 切帧；USART3 115200 输出诊断日志。TIM6 提供 1 ms 时基，TIM7 由代码配置为 50 kHz，产生 20 µs 脉冲节拍。5 路限位与 1 路急停均上拉接入 EXTI，四轴 STEP、DIR、ENA 为 GPIO 输出。FreeRTOS 堆 20 KB，开启栈溢出检查。

## 注意事项

修改.ioc前先了解arm_borad.c覆盖了什么，修改 .ioc 后重新生成，需核对时钟、串口波特率与中断优先级；细分 16 与减速比 32/9 必须和驱动器拨码一致，否则角度整体偏移；脉冲中断内不做浮点运算与阻塞操作；首次上电先确认限位与急停的有效电平。
